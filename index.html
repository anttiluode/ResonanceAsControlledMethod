Resonance is not memory.
It can be a way to read memory.

Write four persistent changes into the boundary of a reflecting ellipse. Let the wave die. Then choose where and when to send a fresh ping. The question is not which echo is strongest, but which ping best distinguishes the records.

01 / persistent medium

Write the wall

Four binary wall patches are mapped onto four of the eight ellipse sectors. They are material parameters, not amplitudes carried by the wave.

Known / blind record

During a blind trial the entire wave field and wall colors are concealed. The inference algorithm receives only the one-cell receiver trace you request.

What is assumed?
Wall writing is external and permanent. This machine does not yet discover a plasticity rule. Its memory is read through classical linear waves and repeated scattering.

06 / a controlled contest

Does questioning help?

A seeded noisy recognition test. All methods get the same number of one-cell pings and the same dictionary of all sixteen clean echoes. This tests probe selection, not learning new wall combinations or reducing calibration cost.

Methods: adaptive posterior-weighted separation, fixed focus/late, cycling late sources, and uniformly random source/window.

Falsification, not illustration
If adaptive does not beat the strongest fixed or cycling strategy over many shared test words/noise seeds, the claim that active questioning helps in this setup fails. No invented accuracy figures are shown.
Method ledger

What the instrument establishes — and what it does not

Known mathematics: finite-difference damped scalar wave propagation on an ellipse, discrete Neumann reflections with binary Robin boundary springs, Bayesian Gaussian template discrimination, and adaptive measurement selection. For each fixed wall the wave evolution is linear; joint wall changes yield non-additive echoes through repeated scattering.

Measured locally by this page: which of six real point-receiver interrogation actions separates sixteen pre-calibrated wall records under a chosen noise and shot budget. Adaptive choice uses the current posterior's expected pairwise waveform separation — a heuristic, not an optimal-information theorem.

Not demonstrated: physical hardware, spontaneous memory writing, generalization to unseen wall combinations, an exponential calibration saving, or a consequence of the October 2026 OpenAI Euclidean local-smoothing theorem. The paper inspired questions about coherent observation, but its free-wave proof does not transfer to this bounded cavity.

Research path: This is a new, deliberately small interrogation interface alongside Kavitaatio and WallMemoryLaw. The difficult next project is geometrically sparse calibration of more wall bits, not adding another virtual FFT filter.
